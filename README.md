A Python project I coded primarily from 7th-8th grade 

It involves an entirely text-based dungeon adventure, based on 2D arrays, maps, and even the distance formula to ensure difficulty of monsters quickly ramps up as you go.

You can play it by locally downloading the repository and it can be run in any IDE with Python 3 or above installed! A short demo of the app is attached at [Dungeon_Adventure_1.2_Demo.mov](Dungeon_Adventure_1.2_Demo.mov).
